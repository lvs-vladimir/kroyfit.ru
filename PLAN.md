## 🎯 ПОЛНЫЙ ФУНКЦИОНАЛ

### Главная страница
- VK ID SDK кнопка логина
- Информация о 3 курсах
- Контакты и CTA

### Профиль пользователя (/profile)
- Аватар и информация
- Список купленных курсов
- Статус оплаты
- Дата регистрации

### Личный кабинет (/cabinet)
- Список всех курсов с прогрессом
- Просмотр уроков по курсам
- Отслеживание прогресса (%)
- Статус завершения уроков

### Админка (7 страниц)
1. **Dashboard** - последние покупки, быстрые действия
2. **Курсы** - список, создание, редактирование, удаление
3. **Пользователи** - список, создание, редактирование
4. **Покупки** - история платежей
5. **Настройки (7 полностью функциональных вкладок)**
   - Профиль - редактирование email, имени, пароля (сохраняется в БД)
   - Роли - управление ролями и разрешениями (сохраняется в БД)
   - Администраторы - управление доступом (сохраняется в БД)
   - ВКонтакте - добавление/удаление групп (работает)
   - Email - SMTP конфигурация + шаблоны
   - SEO - sitemap, robots, мета-теги
   - Общие - название, email админа
6. **План** - редактирование плана разработки
7. **Логин** - авторизация администраторов

### API (12 endpoints)
- `/api/admin/login` - авторизация
- `/api/admin/settings` - сохранение всех настроек
- `/api/courses` - список курсов
- `/api/courses/:slug` - данные курса
- `/api/users` - список пользователей
- `/api/users` (POST) - создание пользователя
- `/api/vk/invite` - приглашение в VK группу
- `/api/plan` - получить/сохранить план
- `/api/payments/create` - создание платежа
- `/api/payments/webhook` - webhook ЮKassa
- `/api/email/send` - отправка email
- `/api/sitemap.xml` - генерация sitemap

### База данных (SQLite)
- `roles` - роли с 7 разрешениями
- `admins` - администраторы с привязкой к ролям
- `users` - 3 тестовых пользователя
- `courses` - 3 курса (15k, 25k, 12k ₽)
- `purchases` - 3 покупки
- `vk_groups` - подключение групп
