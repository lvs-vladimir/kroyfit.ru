# Промт для ИИ: Редизайн лендинга «Генетика Кроя» (kroyfit.ru)

---

## Контекст проекта

Создай полностью рабочий одностраничный лендинг на **Nuxt 3 + Vue 3 + Tailwind CSS** для школы кройки и шитья «**Генетика Кроя**» в Барнауле. Школа обучает авторской методике точного кроя по Злачевской — одежда садится идеально без примерок. Аудитория — женщины 25–55 лет, которые хотят шить для себя, семьи или на продажу.

---

## Дизайн-концепция: «Haute Couture Atelier» 2026

### Философия
Дизайн должен ощущаться как высококлассное ателье мирового уровня, при этом оставаясь тёплым и доступным. Вдохновение: лаконичность Maison Margiela, тактильность ткани, точность портновских инструментов. Не похоже на обычную «школу кройки» — это **институт точного мастерства**.

### Цветовая палитра
- **Фон**: тёплый слоновый (кремовый) `#F5F0E8` — как качественный хлопок
- **Акцент 1**: глубокий антрацит `#1C1917` — как пространство ателье
- **Акцент 2**: терракота/медь `#C4622D` — тёплый, живой, ручной труд
- **Вспомогательный**: пыльный розово-бежевый `#E8D5C4`
- **Текст**: `#2D2420` — почти чёрный, тёплый

### Типографика
- **Заголовки**: `Cormorant Garamond` (Google Fonts) — высокая мода, элегантность
- **Подзаголовки**: `Playfair Display Italic` — художественный акцент
- **Тело текста**: `DM Sans` — читаемый, современный
- Крупные заголовки в hero: 96–120px с tight letter-spacing, смешение normal и italic начертаний внутри одной строки

## Структура секций

### 1. Navigation (sticky)
- Логотип слева: иконка ножниц ✂️ + «Генетика Кроя» в Cormorant Garamond
- Меню: Курсы / О нас / Результаты / Контакты
- CTA кнопка справа: «Записаться» — тёмная с медным hover
- На скролле: появляется тонкая линия-разделитель снизу, backdrop blur

### 2. Hero Section — главный экран
- **Левая половина (60%)**: 
  - Маленький тег сверху: `「 БАРНАУЛ · С 2014 ГОДА 」` — в capslock, letter-spacing 0.3em, цвет меди
  - Гигантский заголовок в 2 строки: первая строка — «Шейте одежду» обычным весом, вторая — *«как вторая кожа»* курсивом и в цвете меди
  - Подзаголовок: «Авторская методика точного кроя по Злачевской. Идеальная посадка — без примерок.»
  - Две кнопки: «Выбрать курс» (тёмная, filled) + «Написать в VK» (outline с медной рамкой)
  - Три метрики горизонтально: **12+ лет** / **500+ выпускниц** / **★ 5.0** — с тонкой вертикальной линией-разделителем между ними
- **Правая половина (40%)**:
  - Большая фотография (placeholder: портновский манекен с тканью в тёплом свете, aspect-ratio 3/4)
  - Карточка-бейдж, которая «всплывает» поверх фото снизу-слева: «Методика Злачевской» с маленькой иконкой иглы
  - Декоративная тонкая пунктирная линия, как выкройка, уходящая за пределы экрана

### 3. Pain Points — «Знакомые проблемы?»
- Заголовок секции: маленький над крупным, двухуровневый
- 4 карточки в сетке 2×2 с hover-эффектом
- Каждая карточка: иконка (SVG), короткий текст проблемы, тонкая рамка
- При hover: карточка поднимается, появляется медный акцент
- Анимация появления: stagger при скролле (Intersection Observer)

### 4. Courses — «Наши курсы»
- Горизонтальный скролл (snap scroll) карточек курсов на мобиле, сетка 3 колонки на десктопе
- Каждая карточка курса: тёмный фон `#1C1917`, белый текст, медный акцент для деталей
- Поля карточки: название, уровень (начинающий / продолжающий), длительность, ключевые навыки, цена, кнопка
- Тонкие декоративные элементы выкройки как фоновая текстура карточки (SVG-паттерн)

### 5. Results — «Результаты наших учениц»
- Заголовок с большим декоративным номером «500+» в фоне (opacity 0.05, огромный шрифт)
- 4 колонки-направления: Гардероб / Ателье / Карьера / Доход
- Каждое направление: иконка + название + 1-2 строки описания
- Горизонтальная линия прогресса или статистика

### 6. About — «Людмила Лукьянова»
- Асимметричный layout: фото слева (вертикальное, с тёплым оверлеем), текст справа
- Имя крупно, должность мелко над именем
- Три факта с медными маркерами: 50+ лет / с 2014 / авторская методика
- Цитата в кавычках-гильомэ «» курсивом
- Декоративная нитка/стежок как разделитель — SVG анимация

### 7. CTA Banner — «Начните сегодня»
- Полноширинная секция с тёмным фоном `#1C1917`
- Крупный заголовок светлого цвета
- Подзаголовок и два контакта
- Кнопки: VK + телефон
- Декоративный фоновый паттерн из ножниц/иголок — очень тонкий, opacity 0.03

### 8. Contacts + Footer
- Три колонки: телефоны / адрес + часы / соцсети
- Карта (iframe Yandex Maps или заглушка) с адресом ул. Профинтерна 7А, Барнаул
- Нижняя строка: копирайт + быстрые ссылки

## Анимации и интерактивность

- **Hero**: текст появляется снизу вверх с opacity 0→1, stagger 100ms между элементами
- **Scroll-reveal**: все секции появляются с `translateY(30px)` → `translateY(0)` через Intersection Observer
- **Числа-счётчики**: при попадании в viewport цифры «накручиваются» (12, 500, 5.0)
- **Карточки курсов**: hover с лёгким scale(1.02) и тенью
- **Кнопки**: медный underline animation при hover (псевдоэлемент ::after с transform)
- **Навигация**: smooth scroll к секциям
- **Декоративная нитка**: SVG path с stroke-dasharray анимацией при появлении секции о преподавателе

## Финальная цель

Лендинг должен производить впечатление **высококлассного европейского ателье**, которое решило запустить курсы. Пользователь заходит и думает: «Здесь точно научат шить хорошо» — ещё до того, как прочитал хоть одно слово.
